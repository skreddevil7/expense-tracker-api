# Expense Tracker API

A RESTful API for tracking personal expenses, built with Java and Spring Boot.

## Goals

- Build REST APIs using Spring Boot.
- Persist expense data in a relational database.
- Add validation and centralized exception handling.
- Write unit and integration tests.
- Containerize the application using Docker.
- Set up a CI/CD pipeline.

## Tech Stack

- Java
- Spring Boot
- Maven
- Git and GitHub
